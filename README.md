# Responsive Food Website

## Overview

Responsive Food Website is a frontend web development project built using HTML, CSS, and Bootstrap. The website is designed to provide an attractive and user-friendly interface for a food delivery business. It showcases various sections such as menu items, healthy food options, special offers, delivery services, and contact information.

## Features

* Responsive design compatible with desktop, tablet, and mobile devices.
* Attractive homepage with modern UI design.
* Explore Menu section to showcase food categories.
* Why Choose Us section highlighting service benefits.
* Healthy Food section promoting nutritious meal options.
* Delivery and Payment section with service information.
* Special Offers section.
* Contact section for customer interaction.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 4

## Project Structure

* responsive-food.html
* responsive-food.css
